# Slipper Zero+ | Portable Wi-Fi Penetration & Defence Toolkit

## Overview

**Slipper Zero+** is a low-cost, portable Wi-Fi penetration testing and defence toolkit designed to simplify wireless network security analysis using embedded hardware.

The project aims to integrate offensive wireless security testing and defensive network monitoring into a unified platform. It focuses on identifying wireless networks, monitoring network activity, simulating controlled deauthentication attacks, and detecting suspicious wireless behaviour.

A web-based dashboard provides an accessible interface for network scanning, device visualization, system monitoring, and security alerts, reducing dependence on traditional command-line penetration testing tools.

## Key Features

### Wireless Security Testing
- Wi-Fi network discovery and scanning.
- Controlled deauthentication attack simulation.

### Defensive Monitoring
- Wireless packet monitoring.
- Detection of suspicious deauthentication activity.
- Lightweight intrusion detection approach.
- Security alerts for abnormal network behaviour.

### Web-Based Dashboard
- Interactive web interface.
- Network and device visualization.
- Signal strength monitoring.
- System activity and alert display.
- Control interface for supported operations.

## System Architecture

The project follows an embedded wireless security architecture consisting of:

1. Wireless network discovery and monitoring.
2. Packet analysis and suspicious activity detection.
3. Controlled wireless security testing.
4. Web-based visualization and system control.

## Project Objectives

- Develop an affordable and portable wireless security toolkit.
- Simplify wireless penetration testing for educational purposes.
- Integrate offensive and defensive security capabilities.
- Provide real-time visibility into wireless network activity.
- Demonstrate embedded systems applications in cybersecurity.
