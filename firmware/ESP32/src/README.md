# ESP8266 Firmware

## Overview

This directory contains the embedded firmware for the **Slipper Zero+ Wireless Security Toolkit**.

The firmware is designed for the ESP8266 platform and supports wireless network discovery, Wi-Fi monitoring, web-based device management, and wireless security testing in authorized lab environments.

## Technical Specifications

Hardware Platform: ESP8266
IDE: Arduino IDE
Firmware Language: C/C++
Connectivity: Wi-Fi

## Key Features

- **Network Discovery:** Scans and identifies nearby wireless networks.
- **Wi-Fi Monitoring:** Monitors wireless network activity.
- **Web Interface:** Provides browser-based device management.
- **System Configuration:** Supports firmware and device settings.
- **Security Testing:** Supports wireless security testing in controlled environments.

## Installation and Setup

1. Install the Arduino IDE.
2. Install the ESP8266 board package.
3. Install the required libraries and dependencies.
4. Open the main firmware `.ino` file.
5. Select the appropriate ESP8266 board and COM port.
6. Compile and upload the firmware.
