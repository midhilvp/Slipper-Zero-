# ESP8266 Firmware

## Overview

This directory contains the embedded firmware used in the Slipper Zero+ wireless security toolkit.

The firmware is developed for the ESP8266 platform and includes wireless network scanning, monitoring, web server functionality, and supported wireless security testing features.

## Platform

- Microcontroller: ESP8266
- Development Environment: Arduino IDE
- Programming Language: C/C++

## Main Functionalities

- Wireless network discovery
- Wi-Fi monitoring
- Web-based device interface
- System configuration
- Wireless security testing in authorized lab environments

## Setup

1. Install Arduino IDE.
2. Install the ESP8266 board package.
3. Install the required libraries.
4. Open the main firmware `.ino` file.
5. Select the appropriate ESP8266 board and port.
6. Compile and upload the firmware.

Refer to the project documentation for hardware configuration and additional setup details.
